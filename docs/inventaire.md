## Exclusions volontaires

- SSH/GPG, AWS, Kubernetes, Docker, GitHub CLI, comptes mail et clés privées : identités et accès.
- Configurations Codex, Claude, agents, MCP et autres assistants : configuration mêlée aux accès, sessions et chemins de projets ; audit dédié nécessaire avant partage.
- Historique shell, caches, sauvegardes, bases de données et fichiers générés : données de fonctionnement.
- cmux/AiMux : configuration mêlée aux projets et hooks locaux ; aucune copie brute.
- La base chezmoi déjà présente sur la machine reste indépendante de ce dépôt.

## k9s sur macOS

Configuration trouvée dans `~/Library/Application Support/k9s`, hors de `~/.config`. Inclus : `config.yaml`, `aliases.yaml`, `jumps.yaml`, `plugins.yaml`, `views.yaml` et `skins/TokyoNight.yaml`. Exclus : `clusters/`, journaux et sauvegardes. Aucun kubeconfig distribué.

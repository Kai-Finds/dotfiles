In each guide, **the upstream project** means the application and its capabilities; **our settings** means what this repository's files change. A declared plugin may require a download or an external tool before it works.

Each [configuration directory](../home/README.md) also has its own README next to its files. These remain readable on GitHub without being copied into your home directory by chezmoi.

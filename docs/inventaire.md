## Deliberate exclusions

- SSH/GPG, AWS, Kubernetes, Docker, GitHub CLI, mail accounts, and private keys: identities and access.
- Codex, Claude, agents, MCP, and other assistant configurations: settings mixed with access credentials, sessions, and project paths; a dedicated audit is required before sharing.
- Shell history, caches, backups, databases, and generated files: runtime data.
- cmux/AiMux: settings mixed with projects and local hooks; no raw copy.
- The machine’s existing chezmoi source remains independent of this repository.

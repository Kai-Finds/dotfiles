# Library: macOS settings

[← Home](../../README.md) · [Upstream project: macOS and k9s](https://k9scli.io/topics/config/) · [Detailed guide](../../docs/guides/k9s.md)

This directory keeps the macOS location of the k9s configuration. It is not a copy of the machine's Library.

Files live under `Application Support/k9s/`. General preferences, views, aliases and plugins are shared. Logs, backups, cluster data and kubeconfig are not.

Read the k9s README in that subdirectory before use: some shortcuts change the cluster.

## Apply these settings

Read the [installation guide](../../docs/installation.md) and review the chezmoi diff before applying. READMEs stay in the repository; chezmoi never installs them.

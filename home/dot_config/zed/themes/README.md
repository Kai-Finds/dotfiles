# Zed · Catppuccin Mocha

[← Application configuration](../README.md) · [Upstream theme](https://github.com/catppuccin/zed)

`catppuccin-mocha.json` contains the Mocha theme extracted from the official Catppuccin mauve-accent theme family. Our parent `settings.json` selects `Catppuccin Mocha` in dark mode.

Zed loads local themes from `~/.config/zed/themes/`; no theme extension download is required for this bundled file. Restart Zed after applying. Zed itself is not installed by the Brewfile.

Pinned source versions are recorded in [theme-sources.json](../../../../docs/theme-sources.json); MIT notices are retained in [docs/licenses/](../../../../docs/licenses/). These assets belong to their upstream authors.

[← Accueil](../README.md)

Si tu découvres cet environnement, lis d'abord le guide Ghostty puis le guide Shell : la fenêtre, le shell et le prompt jouent trois rôles différents.

Dans chaque guide, **le projet d'origine** désigne le logiciel et ses capacités ; **nos réglages** désignent ce que les fichiers de ce dépôt changent. Un plugin déclaré dans une configuration peut nécessiter un téléchargement ou un outil externe avant de fonctionner.

Les [dossiers de configuration](../home/README.md) ont aussi chacun leur README, directement à côté des fichiers. Ils restent consultables sur GitHub sans être copiés dans le dossier personnel par chezmoi.

# Zed · Catppuccin Mocha

[← Application configuration](../README.md) · [Upstream theme](https://github.com/catppuccin/zed)

`catppuccin-mocha.json` holds the Mocha theme, taken from the official Catppuccin family with the mauve accent. The parent `settings.json` selects `Catppuccin Mocha` in dark mode.

Zed loads local themes from `~/.config/zed/themes/`, so no extension download is needed. Restart Zed after applying. The Brewfile does not install Zed.

Pinned source versions: [theme-sources.json](../../../../docs/theme-sources.json). MIT notices: [docs/licenses/](../../../../docs/licenses/). The theme belongs to its upstream authors.
